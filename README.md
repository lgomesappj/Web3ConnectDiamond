## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3ConnectDiamond.git`
2. `cd Web3ConnectDiamond`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3ConnectDiamond, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
